# Plan: トレーニングクイズ（特訓）— 清一色多面待ち・牌効率（有料機能）

> 承認: 2026-07-25（形式・範囲・回数制限・公開範囲の4点をオーナーが決定済み）
> 関連: [タスク分解とPlan運用](../開発ガイド/03_タスク分解とPlan運用.md) / 設計ドキュメント2章

## 1. 目的

牌譜・何切るに続く第3の柱として反復トレーニングを追加し、有料プランの継続価値を作る
（解析枠に次ぐ2つ目の有料理由）。回答速度と正答率を記録し、成長が実感できるグラフで継続動機を作る。

## 2. ハーネス構成要素

- ツール（スキーマ）: クイズ結果スキーマを背骨（@rigel/schema）に追加
- 制約: 無料1日3回のサーバ強制（乱用耐性）
- AI 非関与: 出題・採点は決定的アルゴリズム（待ち・向聴・受け入れは数学的に一意）。Gemini 不使用

## 3. 確定仕様（[決定] 2026-07-25）

- クイズ2種:
  - **清一色多面待ち**: 単色テンパイ13枚を出題 → 待ち牌（1〜9）を全部選ぶ。**完全一致のみ正解**。
    生成は待ち2種以上のテンパイ形のみ（品質フィルタ）。
  - **牌効率**: **1〜2向聴・字牌あり**の14枚を出題 → 受け入れ枚数（種類×残り枚数、全牌残り4枚前提）が
    **最大になる打牌**を選ぶ。同率最大が複数あれば**どれを選んでも正解**。
- セッション形式: **60秒タイムアタック**。時間内に何問解けるか（スコア=正解数。誤答はスキップ扱いで次問へ）。
  出題はシード付き乱数でクライアント生成・クライアント採点。
- 回答中のフィードバックは**○×（正誤）のみ**で正答は見せない（回答直後の正解牌ハイライトは廃止）。
  **正答の見直しは結果画面の「見直しリスト」**で行う: 回答した問題ごとに 問題番号・○×・手牌・
  あなたの回答（清一色=選んだ待ち牌 / 牌効率=切った牌）・正解（牌効率は bestDiscards 全部）を牌表示で並べる。
  60秒経過時に回答中だった問題は含めない。見直しはセッション内のみ（サーバに保存しない・結果送信仕様は不変）。
  （[決定] 2026-07-25 UX変更）
- 回数制限: **無料は1日3回・開始時に1回消費（途中離脱も消費）・JST 0時回復**。有料（next/pro）は無制限。
  **サーバで強制**（開始 API が消費と拒否を持つ。クライアント判定だけにしない）。
- 履歴・グラフ: セッション結果（kind・出題数・正解数・所要ms・日時）を保存。
  マイページに履歴と期間グラフ（正解数/分・正答率の推移）。**本人のみ閲覧**
  （公開プロフィール /u/handle には出さない）。グラフは自前 SVG（依存追加なし）。
- 計測: ANALYTICS_EVENTS に quiz_start / quiz_complete（params: kind。成績・PII は送らない）。

## 4. スコープ外（v1）

- ランキング・対人戦・他人の成績閲覧（チート耐性はこの前提の範囲でのみ設計）
- 人手による出題作成・出題の保存/共有（自動生成のみ）
- 点数計算クイズ・清一色以外の染め手多面待ち
- 場況考慮の受け入れ（河・副露で残り枚数を減らす計算）
- 既存の非スコープ（点数自動計算しない等）は不変

## 5. 影響範囲

- packages/schema: QuizKind / QuizSessionResult（Zod・上限つき）
- packages/ui: 麻雀計算の中核（待ち列挙は既存 tenpai.ts の isWinningShape を再利用して拡張。
  **向聴数・受け入れ計算は新規**）＋シード付き出題生成＋グラフ整形。TDD 最厚（既知手の期待値表）
- apps/api: quiz_sessions テーブル（migration）・開始（消費/拒否）・結果・履歴 API
- apps/web / apps/mobile: 特訓画面（新規導線）・マイページ「特訓」タブ＋グラフ
- 依存追加: 外部なし（workspace 内で apps/api → @rigel/ui を新規参照。FREE_QUIZ_PER_DAY を
  サーバ強制と画面文言で共有するため。@rigel/ui は純 TS・schema のみ依存で Workers に安全）

## 6. 信頼まわり

- AI 出力: 該当なし（Gemini 不使用。解析枠 recordGeminiCalls に触れない）
- 課金: 1日3回はサーバ強制。プラン判定は users.plan 射影（真実源 RevenueCat）を利用
- プライバシー: 成績は本人のみ（他人向け API レスポンスに含めない）。GA4 に成績・PII を送らない

## 7. 受け入れ条件（= 最初の Red 集合）

- [ ] 純正九蓮宝燈（1112345678999）の待ちが9種／既知の多面待ち形が期待値表どおり
- [ ] 既知手の向聴数が期待値どおり（聴牌=0・和了=-1 を含む。七対子・国士も考慮）
- [ ] 各打牌の受け入れ（種類×枚数）と最大集合が既知手の期待値どおり（手牌内の使用枚数は残数から控除）
- [ ] 生成された清一色問題は必ず「テンパイかつ待ち2種以上」、牌効率問題は必ず「1〜2向聴かつ受け入れ差が付く」
- [ ] 同一シードから同一問題列が再現される
- [ ] free の4回目の開始が拒否され、JST 翌日に回復する。next/pro は無制限
- [ ] セッション結果が保存され、本人の期間指定で取得できる。他人からは取得できない
- [ ] 60秒セッションの結果（出題数・正解数・所要ms）がマイページのグラフ整形関数で期間集計できる

- クライアント採点なので厳密なチート耐性はない（本人の成長記録が目的のため許容。
  ランキングを将来やる場合は要再設計 — 本 Plan の前提として明記）

  許容 = カウンタ整合の [決定] 2026-07-12 と同じ扱い。金銭に直結しないため許容）
