## 1. 目的

牌譜・何切るに続く第3の柱として反復トレーニングを追加し、有料プランの継続価値を作る
（解析枠に次ぐ2つ目の有料理由）。回答速度と正答率を記録し、成長が実感できるグラフで継続動機を作る。

## 2. ハーネス構成要素

- ツール（スキーマ）: クイズ結果スキーマを背骨（@rigel/schema）に追加
- 制約: 無料1日3回のサーバ強制（乱用耐性）
- AI 非関与: 出題・採点は決定的アルゴリズム（待ち・向聴・受け入れは数学的に一意）。Gemini 不使用

## 3. 確定仕様（[決定] 2026-07-25）

- クイズ3種:
  - **清一色多面待ち**: 単色テンパイ13枚を出題 → 待ち牌（1〜9）を全部選ぶ。**完全一致のみ正解**。
    生成は待ち2種以上のテンパイ形のみ（品質フィルタ）。
  - **牌効率**: **1〜2向聴・字牌あり**の14枚を出題 → 受け入れ枚数（種類×残り枚数、全牌残り4枚前提）が
    **最大になる打牌**を選ぶ。同率最大が複数あれば**どれを選んでも正解**。
  - **点数計算**（[決定] 2026-07-26 種目追加。同日 v2=採点エンジン方式へ置き換え済み）:
    和了の牌姿（手牌＋副露＋上がり牌を分けて強調）と条件（親/子・自風 東〜北・ツモ/ロン・
    場風 東/南）＋**ドラ表示牌1〜2枚**を出題 → 正しい点数を**4択**で選ぶ。
    翻数・符は表示しない（自分で数えるのが問題）。
    - ルールは**切り上げ満貫なし**（`QUIZ_SCORE_RULES = RulesSchema.parse({ kiriage: false })`。
      7700=子4翻30符ロン / 11600=親4翻30符ロン の古典的な点数を出題するため。Mリーグ既定と異なる点に注意）。
    - **生成 v2**: 手はブロック構築（面子4＋雀頭＋待ち形=両面/カンチャン/ペンチャン/シャンポン/単騎）で
      自由に組み、**採点は `scoreAgariHand`（score-engine.ts: 全分解列挙×高点法）へ全委譲**する。
      v1 の制約（同スート区間分離・役の種類制限・カン上限・意図しない役の棄却）は撤廃。
      **全通常役＋役満・喰い下がり・七対子/国士**が出題対象で、無役（ドラのみ含む）は棄却して再抽選。
    - **副露は0〜2組**（ポン/チー/大明槓/暗槓を混在）・**カンは0〜3組**（三槓子も可。カン3組のときのみ
      副露表示は3組）。**赤5は rules.aka="1" 相当**（各色1枚まで。手中の5の枚数/4 の確率で置換）。
      **ドラ表示牌1枚**（カン出題時は5割で2枚=新ドラ）。染め寄せ（2割で数牌1色）が混一/清一→
      跳満〜三倍満の出題源。
    - **リーチ対応**（[決定] 2026-07-26 追加。**1翻・門前のみ・一発/裏ドラなし**）: 門前手
      （晒しなし。暗槓のみは門前なのでリーチ可）の約5割に rng で riichi を付与し、晒し
      （ポン/チー/明槓）入りは常に riichi=false。エンジン側も「晒しがあるのに riichi=true は
      null」を防御する。立直だけで有役（他役なし+riichi も出題可）。
    - 出題分布は固定シードの決定的スキャンでテスト固定（400問に 6翻+/8翻+/11翻+/fu>=80/副露/カン/

## 3-2. v2: 採点エンジン方式（高点法）（[決定] 2026-07-26 オーナー要望）

点数計算クイズを「構築時に翻符を確定させる」v1 方式から、**任意の和了手を採点できる
エンジン**（`@rigel/ui` の `scoreAgariHand` / score-engine.ts）へ置き換える。
鳴き・三槓子等の役・6/8翻・三倍満・ドラ/赤ドラをオーナー要望どおり出題可能にする土台。

- **入力**: 門前部分（和了牌込み 3n+2 枚）＋副露（pon/chi/kan_open/kan_added=晒し・
  kan_closed=門前維持）＋和了牌＋ツモ/ロン＋自風/場風＋ドラ表示牌。
- **方式**: 標準形（4面子1雀頭）の**全分解を列挙**（counts ベース再帰・副露は固定ブロック）し、
  **和了牌がどのブロックを完成させたかの解釈**（待ち形＝符とピンフに効く）も列挙。
  七対子（門前25符2翻）・国士無双（役満）は特別形。全候補を `handScore`（score.ts）で
  点数化し、**支払い合計が最大**（同点なら翻が大きい方）の解釈を返す＝高点法。
  二盃口 vs 七対子などの排他も高点法で自然に解決する。
- **役の対象範囲**: 通常役＋役満＋**立直**（[決定] 2026-07-26 追加: `AgariContext.riichi`。
  1翻・門前のみ。晒しがあるのに riichi=true は不正入力として null）。
  **一発・その他の状況役（海底/河底/嶺上/搶槓・天和/地和）と裏ドラは対象外**のまま
  （クイズは一発なし・裏ドラなしの前提。スコープ変更しない）。
  - 1翻: 断幺九（喰いタンは rules.kuitan）/ 平和 / 一盃口 / 役牌（白發中・自風・場風。
    連風刻子は2つの役牌=2翻・連風雀頭は4符）/ 門前清自摸和
  - 2翻: 対々和 / 三暗刻 / 三槓子 / 混老頭 / 小三元 / チャンタ・一気通貫・三色同順
    （各喰い下がり1）/ 三色同刻 / 七対子（25符）
  - 3翻: 純チャン・混一色（各喰い下がり2）/ 二盃口（門前）
  - 6翻: 清一色（喰い下がり5）
  - 役満: 大三元・四暗刻（単騎もシングル扱い。ダブル役満バリアントは将来対応）・字一色・
    緑一色・清老頭・四槓子・小四喜・大四喜・国士無双・九蓮宝燈。役満時は他の役・ドラを
    数えない。複数役満の複合は handScore の yakuman 数×multiYakuman で倍加（score.ts と同じ）。
  - ドラ: 表示牌の次位（9→1・東南西北・白發中の各循環）×手牌中の枚数を「ドラn」、
    赤5（0m/0p/0s）を「赤ドラn」の行として加算（**役が1つ以上あるときのみ。ドラのみは無役=null**）。
- **符**: 基本20・門前ロン+10・ツモ+2（平和ツモ20固定）・待ち+2（カンチャン/ペンチャン/単騎）・
  雀頭（役牌+2・連風+4）・刻子/槓子（中張明刻2/暗刻4/明槓8/暗槓16、幺九は倍）・
