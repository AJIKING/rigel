# 07. ローカル開発環境（web + api を双方ローカルで）

本番（`rigel.plaria.co.jp` / `rigel-api.plaria.workers.dev`）に触れず、**localhost だけで
end-to-end（ログイン→作成→編集→保存→公開→再生）を検証**するための手順。リリース前チェックの基準はこれ。

## 構成

```
[localhost:3000] web (next dev)  ──API_URL──►  [localhost:8787] api (wrangler dev)
   Cookie セッション                              ローカル D1（miniflare・本番とは別DB）
```

web と api は**別サービス**。既定では web は本番 Workers api を叩く（`lib/api-server.ts` の
フォールバック）。ローカル完結には **api もローカルで起動し、web の宛先をそこに向ける**。

## 1回だけの準備

### Google OAuth（ローカル用クライアント）
1. Google Cloud Console → 認証情報 → **OAuth クライアント（ウェブ アプリケーション）を新規作成**（名前は `local` 等）。
2. **承認済みの JavaScript 生成元**に `http://localhost:3000` を追加（リダイレクト URI は不要）。
3. 発行された **クライアントID** を控える（反映に数分〜数時間かかることがある）。

### env ファイル（雛形をコピーして値を入れる）
```bash
cp apps/web/.env.example  apps/web/.env.local
cp apps/api/.dev.vars.example  apps/api/.dev.vars
```
- `apps/web/.env.local` … `NEXT_PUBLIC_GOOGLE_CLIENT_ID` に上のIDを入れる（`API_URL`/`NEXT_PUBLIC_API_URL` は既定で `http://localhost:8787`）。
- `apps/api/.dev.vars` … `GOOGLE_CLIENT_ID` に**同じID**、`SESSION_SECRET` に任意のランダム文字列。
- **肝**: web の `NEXT_PUBLIC_GOOGLE_CLIENT_ID` と api の `GOOGLE_CLIENT_ID` は**必ず同一値**
  （idToken の `aud` を api がこのIDで検証するため。不一致だと `/api/session` が 401）。

## 起動

```bash
pnpm dev
```
- ルートの `pnpm dev`（= `turbo run dev`）で **web(:3000) と api(:8787) を同時起動**。
- api の `dev` はローカル D1 のマイグレーション適用（`db:migrate:local`）→ `wrangler dev` の順。
- 個別に動かすなら `pnpm --filter api dev` / `pnpm --filter web dev`。

### VS Code から
- **タスク**（デバッガ無しで起動）: コマンドパレット → 「Run Task」→ **`dev: all (web + api)`**。
- **デバッグ**（ブレークポイント可）: 実行とデバッグ → **`フルスタック: api + web + client（ローカル完結）`** を F5。
  web のサーバ側（Server Component / Action / Route Handler）にブレークポイントを置ける。

## データ分離

- ローカル api は **miniflare のローカル D1**（本番 D1 とは別物）。
  ローカルで作った牌譜は本番に入らない。リセットは `.wrangler/` のローカル状態を消す。

## 注意

- **AI 解析(/analyze)** を試すときだけ `GEMINI_API_KEY` / `CLOUDFLARE_AI_GATEWAY_URL` が必要。
  ログイン・編集・採点・公開・再生の確認には不要。
- セッション Cookie は dev では `secure:false`（http の localhost でも張れる）。
- CORS は api 側で `http://localhost:3000` を既定許可済み（`ALLOWED_ORIGINS` 未設定でも可）。
- 課金(`/billing/*`)は `STRIPE_*` 未設定なら 501（ローカルでは通常触らない）。
